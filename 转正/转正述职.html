03 / HIGHLIGHTS
重点工作 · 性能优化
阶段一 · 原组件深度优化
Event 渲染重构5000+ 压测预加载调优 设备日历缓冲区
  • 自定义 event 全面重构，改用 domConfig 格式渲染，降低开销
  • 移除单个 event 右键绑定，改为全局单一绑定，减少内存占用
  • 锁定、选中事件只重渲染相关 event，避免全量刷新
  • 调整预加载阈值，5000+ 工序下达成流畅体验
  • 设备日历：数据结构重设计，虚拟滚动 + 双维度缓冲区，滚动防抖调优
阶段二 · 基于 Canvas 从零重写
Canvas 渲染引擎AI 提效npm 包发布
  • Bryntum Scheduler 性能瓶颈难以突破，决定基于 Canvas 重新设计渲染架构
  • 借助 AI 大幅提升开发效率，聚焦架构设计和性能调优
  • 支持 10000+ 工序流畅渲染，拖拽、缩放体验大幅提升
  • 丰富配置项：缩放等级、时间范围限制、自定义 event 渲染、右键策略等
  • 发布独立 npm 包（GitHub Package），主产品集成进度 95%+
